# Todo List (React + TypeScript)

A clean and simple Todo List application built with React 18, TypeScript, and React Icons.

## Features

- **Add Tasks**: Quickly add new tasks to your todo list.
- **Toggle Completion**: Mark tasks as completed or active.
- **Edit Tasks**: Update the text of existing tasks inline.
- **Delete Tasks**: Remove tasks from the list.
- **Filter Tasks**: Filter your tasks by **All**, **Done**, or **Todo**.

## Tech Stack

- **React 18**
- **TypeScript**
- **React Icons**
- **Create React App** (`react-scripts`)

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## Available Scripts

- `npm start`: Runs the app in development mode.
- `npm run build`: Builds the app for production in the `build` folder.
- `npm test`: Launches the test runner.
